# About Me project

A playful one-page personal website for Samuel W. (flight instructor and business manager in Anchorage, AK).

## The project
- Plain HTML and CSS only: `index.html`, `style.css`, and an `images/` folder. No frameworks or build tools.
- Published with GitHub Pages from the `main` branch.
  - Repo: https://github.com/samuelwarner-max/about-me
  - Live: https://samuelwarner-max.github.io/about-me/
- `cheatsheet.txt` is Samuel's personal git/VS Code reference. Update it when we learn new workflows.

## About Samuel
- Not a coder. This project is for learning VS Code, Claude Code, and git.
- Prefers step-by-step guidance in plain English.

## How to work with Samuel
- Explain what a command or code change does before doing it, and avoid jargon (or define it).
- Let Samuel run the git commands himself (add, commit, push) while I guide. Don't commit or push for him unless he asks.
- Before a bigger change, suggest committing first and using a branch.
- When giving terminal commands, give them one step at a time and say what output to expect.
- Remind him to check the project folder with `pwd` if he seems to be in the wrong place (the folder name has spaces, so paths need quotes).

## Site rules
- Keep the look playful: sky-blue background, yellow and red accents, tilted cards, rounded corners, drifting translucent clouds.
- Photo filenames are case-sensitive on GitHub Pages. Match them exactly (e.g. `something-i-built.JPG`).
- Keep photos reasonably small (under about 1 MB) so the page loads fast.
- This site is public. Don't add personal contact details (email, phone, address) without asking first.
- Use `git add <files>` rather than `git add .` where possible. `.DS_Store` is ignored via `.gitignore`.
